Connect Efficiency output to your existing cockpit

Installs Phase 2 into the HTML file you choose. Your roster, Crown hours, role corrections, Prep KG, complaints, PO and other saved cockpit data stay in that same file.

  1. In your working cockpit, click Save and check that the latest changes are in the HTML file. Keep that tab open and pause auto-save while updating.
  2. Click Choose existing cockpit and install Phase 2. Select the saved Phase 1 master HTML and allow editing.
  3. After verification, reopen the same file. Go to Daily Labour / UPLH and check the 13 October figures. Save once more when you make later edits.

The updater saves the entire previous file in this browser before opening a writer and checks the written file after closing it. No new dashboard copy is downloaded automatically.

Ready. Your existing cockpit file is changed in place after its data blocks are checked.
