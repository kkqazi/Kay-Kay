Source dates, assumptions and review rules

Repeated allocations for the same employee number and source date count once, including appearances in both agencies. A missing employee number uses the normalised name. Different locations remain visible together in a review row; their single 8-hour estimate is not distributed between units. Source rows are retained. Allocation dates are not shifted for night shifts. No estimates have been added to Crown clock hours or UPLH.

Mixed Sanitiser labels use provisional IDL for the 8-hour estimate. The Labour Report must confirm any split. REVIEW is an unresolved class, not zero hours. Source dates outside 2020–2026 are retained with a warning. Rows without a valid date or name are excluded from the person-day view and counted below.
