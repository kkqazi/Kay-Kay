# Quality: complaints per thousand and per million

1. Save your current cockpit.
2. Extract this ZIP and open `Cockpit_Quality_Rates_Updater.html` in Chrome or Edge.
3. Select your latest saved cockpit HTML, then click **Download updated cockpit**.
4. Open the updated file and go to **Quality → Overview**.

**Per million units (CPMU)** appears beside **Per thousand units (CPKU)**. Both use the same selected dates, unit, eligible complaints and Labour Report production volume. CPMU = complaints ÷ units made × 1,000,000. It uses the unrounded calculation, rather than multiplying the displayed CPKU number.

Both KPIs show the same percentage change against the comparison window. Clicking either opens **Labour × Quality**, where the weekly table and its Excel export show both measures. The weekly detail also includes CPMU. Trend charts retain their existing per-thousand scale.

Where separate production volume is unavailable, both rates show a dash and explain the missing denominator. A week with production volume and zero eligible complaints shows zero. The existing exclusion of unattributed complaints and weeks without production volume is retained.

This updater changes Quality display code only. Saved complaints, product mappings, commentary, financial records and settings are retained. Nothing is uploaded; the original file is left unchanged. Existing product-register, Quality mapping and commentary amendments remain in place.
